# What the seven games duplicate and what the shell should own

Measured on main `0f0f3b5f` (2026-10-02) plus `origin/hive-drag` for hive's dragger, by reading
every game's `src/`, `page.ts`, `main.ts` and `theme.css` against `web/shared/{ui,lib,edge,markup,
styles,net}`, the e2e fixtures and `tools/parity/computed-styles.ts`. Every line count is `wc -l`;
"identical" means `diff` is empty once comments are stripped. This is the audit the owner asked for
("review the games for stuff that can be hoisted to the SHELL. We should keep it DRY"); every hoist
below is its own follow-up row, nothing here changes code. It continues
[dry-round-2.md](dry-round-2.md), which measured gin, backgammon and fidice: the four games since
(briscola, then uno, flip7 and hive copied from it) multiplied the shapes that doc left "shared by
shape, not by module" to four, five and seven copies.

## 1. The answer in six lines

1. The shell already owns the reducer, the boot, the sessions, the home, the markup partials and the
   cue player. What the seven games still copy is the **glue between them**: adapters, label
   builders, intent tables, id lists and two-line wrappers, each spelled per game.
2. Four pieces are **byte-identical in six to eight games** (rows A, C, N, J): about 400 lines of
   source and 660 lines of tests that re-test shared code. They go first; none touches a golden.
3. Three pieces are **one shape in all seven** with a game name or a view accessor as the only
   variable (rows K, E, M): the `net/host.ts`+`guest.ts` pairs, the resume and handoff labels, the
   storage key tables.
4. Two pieces are **shell state the games keep in their own `Table`** (rows F, P): the history sheet
   and the result-dismiss flag (four names for one boolean), and the cue machine around
   `cuesBetween`.
5. The **result sheet** (row G) is the one hoist with real risk: four markups of one sheet, pinned
   by the computed-styles goldens of every game; it lands with one re-record.
6. **Left alone**: the seat chips (five designs), the draggers (thin already), the pause sheet (one
   copy), and every rules/about/glossary table (copy over a shared mechanism).

## 4. The top five: signatures and the diff each leaves

### A. `createFx` into the boot

```ts
// web/shared/edge/cuePlayer.ts
export const shellFx = <C extends string>(
  cues: Readonly<Record<C | 'tap', CueSpec>>,
  pref: Pick<SoundPref, 'write'>,
): ((deps: FxDepsOf<C>) => CuePlayer<C>) =>
  ({ store, ...deps }) => createCuePlayer({ ...deps, cues, persist: (s) => pref.write(store, s) });

// web/shared/edge/boot.ts: `fx` becomes optional; the default is
//   shellFx(cfg.cues.table, cfg.prefs.sound)
// so ShellConfig.cues grows `table: Readonly<Record<Cue<G>, CueSpec>>` beside `initial`.
```

Per-game diff: `src/fx.ts` and `src/fx.test.ts` deleted in all seven (rps keeps a two-line
`createFx = shellFx(CUES, SOUND_PREF)`); `main.ts` drops `fx: createFx` and its import;
`shellConfig.ts` gains `cues: { initial: INITIAL_CUES, table: CUES }`. The shared player's test
gains the one case the game tests held (persist to the game's key, read back through `shellStore`).

### B. The N-seat waiting copy

```ts
// web/shared/ui/seatCopy.ts (lint-pure, beside shell.ts)
export type SeatedVerb = 'deal' | 'start' | 'roll';
export const seatedCopy = (
  o: Readonly<{ verb: SeatedVerb }>,
): Pick<
  ShellConfig<ShellTypes>['copy'],
  'hostRoom' | 'waiting' | 'joined' | 'seatLeft' | 'guestGone' | 'roomFull' | 'notEnough'
> => ({ ... });
export const emptySeatName = (seat: number): string => `Seat ${String(seat + 1)}`;
export const parseSeatCount = <N extends number>(
  counts: ReadonlyArray<N>,
  raw: string | undefined,
  fallback: N,
): N => counts.find((n) => String(n) === raw) ?? fallback;
```

Per-game diff: uno, flip7, briscola lose the ten helpers (~40 lines each) and spell
`copy: { ...seatedCopy({ verb: 'deal' }), leaveLocal: LEAVE_LOCAL_MSG, leaveOnline: LEAVE_ONLINE_MSG, opening: OPENING_MSG, connecting: connectingMsg, handoff: handoffMsg }`;
`parseOpts` becomes
`(raw, cur) => ({ seatCount: parseSeatCount(SEAT_COUNTS, raw.players ?? raw.localPlayers, cur.seatCount) })`.
fidice keeps its two differing strings as overrides after the spread. gin, backgammon and hive
replace their one-line `hostRoomMsg` with `seatedCopy({ verb })`'s `hostRoom`. The three
`shellConfig.test.ts` "N-seat copy" blocks collapse into `seatCopy.test.ts`.
