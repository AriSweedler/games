# DRY review, October 2026: Flip 7 read whole

Measured on main `00341ef5` (2026-10-02), after the DRY pass landed (hoists A, B, C+D, E, F, G+I,
J, K, L, M, N, O, P of [shell-hoist.md](shell-hoist.md) and graphs 1-8 of
[shell-call-graph.md](shell-call-graph.md), PRs #47-#74). One agent read `web/games/flip7/` end to
end (every file but the engine's tests) with shell-call-graph.md §5 beside it, then the same file
in UNO, hive, briscola and fidice wherever Flip 7's line looked like a copy, and
`web/shared/{ui,edge,markup,net,lib}` for what the shell exports and who calls it. It is the fresh
read the owner asked for last ("Be a good developer"): §2 is every line of Flip 7 that is not
engine, view adapter, table paint or theme, with the shell function it should have been; §3 every
shell export with fewer than two callers; §4 every place two games still differ only in spelling;
§5 judges the two findings handed in; §6 the new-game template; §7 the rows. Each finding has a
file:line and a one-line fix. Nothing here changes code. §8, added 2026-10-03 once the sixteen rows
had landed, is what they left and what a player sees differently.

The owner's standard, as the rows were cut against it: the shell owns every shape that repeats; a
game keeps its engine, its view adapters, its table paint and its theme, and reads as a short,
composable declaration over shell functions. "Engine" is `src/engine/`; "view adapter" a pure
function from the engine's `State`/`View` to a value the shell or the paint reads (`pauseFor`,
`cueKey`, `cuesBetween`, `viewer`, `revealer`, `myTurn`, the `engine.*`/`result.*` members);
"table paint" the painters and binders of ids only this page has; "theme" `theme.css` and
`ui/motion.ts`.

## 1. The answer in eight lines

1. Flip 7 is 1,493 lines outside `src/` plus 3,772 in it; of the 1,650 that are neither engine
   nor test, about **540 are shell shapes spelled again**: 103 of them one hand-written grid that
   UNO already gets from `seatNamesHtml` (§2.2), 30 the `act`-by-role switch every game carries
   (§2.6), 95 a `ui/home.ts` that is UNO's with the constants renamed (§2.7).
2. The biggest shape left in every game is **`act` by role** (local applies and `localBroadcast`s,
   host applies and `broadcast`s, guest `send`s or hears `NOT_CONNECTED_MSG`): seven copies of one
   switch, each 30 lines, whose only game part is the local actor, which every game already spells
   as `local.revealer`. One shell `act` and the seven go (§2.6, §7 row 1).
3. The config still asks a game to **spell the shell's own defaults back to it**: `tabs`, `modes`,
   `names.default: 'Ari'`, the two leave messages, `opening`/`connecting`/`handoff` copy,
   `cues.initial`, `home: { read, apply }`, `result.keyOf`, `frames: { lobby, state, toast, action,
   join }`, nine `''` markup slots, the endgame placeholder. About 40 lines per game that say
   nothing (§2.3, §2.4, §2.2).
4. **The seat count is one shape in five spellings**: `Opts`, `DEFAULT_OPTS`, `parseOpts`,
   `seatNames`, the `opts` block, `decodeOpts`, `PLAYERS_PREF`/`readOpts`/`writeOpts`, `EXTRA_SEATS`
   and the ten `pNName` keys nobody reads. One `seatCountOpts(SEAT_COUNTS, seatsOf)` in the shell
   replaces ~45 lines in each of uno, flip7, briscola (§2.3, §2.4).
5. Three things are **spelled twice inside Flip 7 itself**: "Waiting for X to deal the next round"
   (`state.ts:138`, `render.ts:215`), the reveal label `'Start'` (`page.ts:33`, `render.ts:66`),
   and the status list (`engine`'s `Status`, `state.ts:149`, `motion.ts:170`, `render.ts:58`).
6. **One copy bug a player reads**: `ui/about.ts:6` says "Two to six players"; the page seats two
   to twelve.
7. Of the shell's ~330 exported values, **about 70 have no caller outside their own file and the
   tests** (§3). Three groups: exported only so a test can reach them (un-export, test through the
   caller), superseded by a later hoist (`paintConnDot`, `paintHandoff`, `paintScreen`,
   `extraNamePref`: delete or fold), and one adopter (`cuesFor` hive, `localSeated` gin,
   `seatingFault` fidice: inline, or keep as the hook it is).
8. `tools/new-game/templates.ts` scaffolds a game as it looked before graphs 3-8: `SCREENS`,
   `paintConnDot`, `paintHandoff`, `hostContextOf`, a local `refuse`, no `paintShellChrome`, no
   `shellButtons`, no `seatedCopy` (§6). Every row in §7 lands in the template too, or the next
   game starts a new DRY pass. (Record of the review: since #81 and #91 the template scaffolds the
   post-hoist game and `tools/new-game.test.ts` pins that none of these tokens is in it.)

## 5. The two findings handed in

### 5.1 A card's flight stacks above the result sheet

`web/games/uno/theme.css:337-342` puts `.flyer` at `z-index: 60`; `web/shared/styles/shell.css:331`
puts `.overlay` at 50, and the comments at `shell.css:245` and `:363` record the order as the
design ("overlays 50, flyers 60, the toast 100"). On UNO the last play of a game wins it: `paint`
(`render.ts:180-190`) plans the flight, repaints the table, which opens `#resultOverlay`
(`render.ts:160`), then launches the clone, so for `--fly-ms` the card glides over the sheet's
title. briscola (`theme.css:1421-1426`) and backgammon (`theme.css:1973-1981`) spell the same
`.flyer` (fixed, inert, 60) and would show the same the moment a flight and a sheet coincide.

Judged: real, and a shell bug rather than UNO's. Nothing that flies should outrank a sheet: the
curtain (an overlay) is opaque on purpose so the seat that just played is hidden, and a flight that
showed through it would leak the card. The drag ghost (`briscola theme.css` `.drag-ghost`, 60) is
never alive while a sheet is open. Fix: one `.flyer` base rule in `shell.css` (`position: fixed;
pointer-events: none; z-index: 40`) with a CONTRACT.md row, the three themes keeping only their
transitions, and the two comments rewritten ("flyers 40, overlays 50, the gate 90, the toast 100").
No golden pins `.flyer` (transient), so it is a shell.css edit with no re-record; the class itself
stays the game's (`launchClone` adds what the caller passes), so the proof is the CONTRACT.md row
and one look at the UNO story PNG of the result sheet.
